# Hello, World

첫 글입니다. Sphinx + Furo + MyST로 홈페이지를 시작했습니다.

## 왜 Sphinx인가

- Python 생태계에 익숙해서 도구가 손에 잡힘
- MyST로 Markdown 문법을 쓸 수 있고, 동시에 RST의 풍부한 디렉티브도 활용 가능
- `sphinx-design`으로 카드, 그리드 같은 UI 요소를 쉽게 추가
- GitHub Actions로 푸시할 때마다 자동 배포
